### How to make your own Opium link:
1. make sure you have your own github account and are signed in
2. fork this repository
3. head to https://www.jsdelivr.com/github
4. on github, click on index.svg, then copy the url.
5. go back to jsdelivr and paste the link where it tells you to (the github link textbox)
6. copy the link it gives you (ex. https://cdn.jsdelivr.net/gh/livetodevelop/opiumsvg@main/index.svg)
7. you made a proxy link!
